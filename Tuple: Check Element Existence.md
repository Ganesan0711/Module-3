
# Tuple in Python: Check Element Existence

## 🎯 Aim
To write a Python program to check whether the elements 'n' and 8 exist within a given tuple.

## 🧠 Algorithm
1. Define a tuple `x` containing letters and numbers.
2. Use the `in` operator to check whether the string `'n'` exists in the tuple.
3. Use the `in` operator to check whether the integer `8` exists in the tuple.
4. Print the results.

## 🧾 Program

```python
x = ('a', 'n', 'p', 5, 8, 10)

print("'n' exists in tuple:", 'n' in x)
print("8 exists in tuple:", 8 in x)
```

## 💻 Output

```text
'n' exists in tuple: True
8 exists in tuple: True
```

## ✅ Result
Thus, the Python program to check the existence of the elements 'n' and 8 in a tuple using the `in` operator was executed successfully.
